- 2026-09-11 — **Gate G1 (Blackwell) — GO.** ctranslate2 4.8.2 on this RTX 5070 Laptop (cc 12.0): `int8_float16` is in `get_supported_compute_types('cuda')` **and** an actual `transcribe()` call ran end to end at that compute type (the first check alone is not proof — an earlier attempt reported `int8_float16` supported and then crashed with `libcublas.so.12 is not found`, because `env.sh`'s path-resolution one-liner used `nvidia.cublas.lib.__file__`, which is `None` on a PEP 420 namespace package; fixed to use `__path__[0]`). Correction for Stage 0 Tasks 5/7: "warm the model at process start" must include one throwaway `transcribe()` call, not just constructing the model object, or the first real user utterance eats the 7s stall instead.
